# Global Table — เว็บไซต์ร้านอาหารนานาชาติ

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิดไฟล์ `index.html` ด้วย Chrome / Edge
3. เว็บไซต์ใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

## ฟังก์ชันใน Demo
- หน้าแรกและข้อมูลร้าน
- เมนูอาหาร 12 รายการ
- ค้นหาและกรองหมวดหมู่
- ตะกร้าสินค้า + เพิ่ม/ลดจำนวน
- คำนวณยอดรวมและค่าส่ง
- สมัคร/เข้าสู่ระบบแบบ Demo
- Checkout / ที่อยู่ / เบอร์โทร / วิธีชำระเงิน
- สร้างเลขออเดอร์และติดตามสถานะ
- ประวัติการสั่งซื้อ
- รีวิวลูกค้า
- โปรโมชั่น
- หน้าผู้ดูแลร้าน
- Responsive สำหรับมือถือ
- ใช้ localStorage เก็บข้อมูลในเครื่อง

## หมายเหตุ
เวอร์ชันนี้เป็น Front-end Demo ด้วย HTML/CSS/JavaScript ตามที่ขอ
ยังไม่มีฐานข้อมูลหรือการชำระเงินจริง หากจะนำขึ้นใช้งานจริงควรต่อ Backend + Database และ Payment Gateway
